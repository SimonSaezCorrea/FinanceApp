- La base de datos donde viven tus cuentas y movimientos ya no tiene acceso desde internet: solo
  la alcanza el servidor de mifik.

## Mejoras

- Si el servidor que atiende la app falla, se recupera solo, y nos llega un aviso para revisarlo.
