# Implementation Plan: Transactions View Redesign

**Branch**: `005-transactions-redesign` | **Date**: 2026-06-28 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/005-transactions-redesign/spec.md`

## Summary

Replace the bare `TransactionsRoute.tsx` list with a production-ready Transactions screen: a multi-currency KPI strip, a filter bar (segmented type control + account/card selector + category search + date range), a sortable table with category icons, and action buttons (+ Movimiento / Importar). Pure frontend — no API or schema changes.

## Technical Context

**Language/Version**: TypeScript 5 — React 18 / Vite (`apps/web`)

**Primary Dependencies**: existing only — TanStack Query, react-i18next, Lucide React, Tailwind CSS, `shared/ui` primitives (`Segmented`, `Select`, `Input`, `Card`, `Badge`, `Table`, `Dialog`, `states`), `@finance/contracts`, `@finance/money`

**Storage**: N/A (no backend change)

**Testing**: Vitest — unit tests for `summarizeByCurrency`, `categoryIcon`, and client-side filter logic; component smoke tests for `TransactionKpiStrip` and `TransactionTable`

**Target Platform**: Vite SPA, `apps/web`

**Performance Goals**: KPI re-computation < 16 ms for ≤ 500 visible rows (client-side `reduce`)

**Constraints**: tokens-only styling (no hardcoded hex); i18n parity es/en; `pnpm check:boundaries` green; no new runtime dependencies

**Scale/Scope**: one route file replaced + 4 new components + 1 utility module + i18n additions

## Complexity Tracking

| Decision | Why | Rejected |
|----------|-----|----------|
| Card filter resolves to parent `bankAccountId` | No API change needed; all card txs booked to parent account | Add `cardId` to transactions contract (scope creep) |
| KPI computation client-side | Zero extra API calls; data already fetched for the filtered period | New aggregation endpoint (unnecessary round-trip) |
| "Convert currency" toggle deferred | No exchange-rate source in system today | Implement with hardcoded rates (unreliable, misleading) |
| Static category icon map | Lucide already installed; zero new deps | Dynamic icon registry (over-engineering for free-text slugs) |
