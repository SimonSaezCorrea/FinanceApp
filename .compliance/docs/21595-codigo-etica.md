# Código de Ética y Conducta — FinanceApp

**Vigente desde:** 2026-09-19 · **Versión:** 1.0

## 1. Propósito
Establece los principios y conductas esperadas de quienes participen en FinanceApp (hoy: su founder, Simón Sáez; a futuro: cualquier socio, trabajador o prestador de servicios), y refuerza el Modelo de Prevención de Delitos.

## 2. Principios
Integridad, legalidad, transparencia, no discriminación, cuidado de la información y de los datos personales de los usuarios — con énfasis particular en el dato financiero, que es el corazón de este producto.

## 3. Conductas prohibidas
- **Cohecho / soborno**: ofrecer o recibir pagos o beneficios indebidos.
- **Lavado de activos**: operar con fondos de origen ilícito o sospechoso.
- **Delitos tributarios**: facturación falsa, evasión, uso indebido de crédito fiscal.
- **Fraude / administración desleal** en perjuicio de la empresa o de terceros.
- **Delitos informáticos**: acceso o uso indebido de sistemas o de los datos financieros de los usuarios — el riesgo más directo para un producto como FinanceApp, dado que el acceso privilegiado a la base de datos permite ver saldos, movimientos y deudas de cada usuario.
- **Conflictos de interés** no declarados.

## 4. Datos personales
El tratamiento de datos personales se rige por la Política de Privacidad (`21719-politica-privacidad.md`) y la Ley 21.719. Está **expresamente prohibido** acceder, exportar o usar los datos financieros de un usuario fuera del propósito de operar y mantener la plataforma — incluyendo consultar la base de datos de producción por curiosidad, sin un motivo de soporte/debugging documentado.

## 5. Canal de denuncias
Cualquier persona puede denunciar incumplimientos de forma anónima escribiendo a **simon.alejandro.saez@gmail.com** (canal provisional mientras el equipo es de una persona; ver `21595-reglamento-canal-denuncias.md` para la limitación reconocida de que hoy el mismo Encargado de Prevención es quien recibiría una denuncia sobre sí mismo). Se garantiza confidencialidad y **no represalias**.

## 6. Consecuencias
El incumplimiento se sanciona según el reglamento interno (a formalizar cuando exista personal) y la ley, sin perjuicio de las acciones legales que correspondan.

## 7. Aceptación
FinanceApp difunde este código. Mientras el equipo sea de una persona, la aceptación la deja constancia el propio Encargado; se exigirá aceptación formal a cualquier persona que se incorpore.
